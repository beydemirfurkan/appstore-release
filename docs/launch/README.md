Copy for listing and announcing v3.0.0. The maintainer submits each of these by hand.

| Where                                  | How it lists you                                                 | File                                              |
| -------------------------------------- | ---------------------------------------------------------------- | ------------------------------------------------- |
| [skills.sh](https://skills.sh)         | Automatic. The first `npx skills add` with telemetry on lists it | nothing to send, see [skills-sh.md](skills-sh.md) |
| MCP Registry                           | Automatic. The release workflow publishes `server.json`          | nothing to send                                   |
| Claude directory (claude.ai/directory) | Plugin bundle submission form, reviewed by Anthropic             | [claude-directory.md](claude-directory.md)        |
| ComposioHQ/awesome-claude-skills       | Pull request                                                     | [awesome-lists.md](awesome-lists.md)              |
| VoltAgent/awesome-agent-skills         | Pull request, after the skill has some installs                  | [awesome-lists.md](awesome-lists.md)              |
| X / LinkedIn                           | Post, with the promo video attached                              | [announcement.md](announcement.md)                |

Attach `appstore-release-promo.mp4` (16:9) or `appstore-release-promo-square.mp4` (1:1) from the GitHub release. Use `docs/social-preview.png` as the repository's social preview: GitHub → Settings → General → Social preview.
